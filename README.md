# موقع ع الفرازة

- `index.html` — الموقع اللي بيشوفه الزباين.
- `data.js` — الأسعار والعروض والعروض الخاصة والبراندات. **ده الملف الوحيد اللي بتعدّله.**
- `admin.html` — صفحة تعديل سهلة: افتحها، عدّل، اضغط "طلّع ملف البيانات"، وانسخه مكان data.js.
- `logo.png` و `logo-white.png` و `offer.jpg` — الصور.

## الرفع على GitHub Pages
1. اعمل repository جديد (مثلًا `3elfaraza`) وارفع كل الملفات دي فيه.
2. Settings ← Pages ← Source: **Deploy from a branch** ← Branch: `main` / root ← Save.
3. بعد دقيقة الموقع يبقى على: `https://اسمك.github.io/3elfaraza/`
